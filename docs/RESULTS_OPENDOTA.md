### Рекомендация

Единственный надёжный способ оценки MMR — **использовать `rank_tier` из OpenDota API напрямую**. Эвристика на основе GPM/KDA не работает, т.к.:
1. GPM зависит от длительности матча, а не от навыка
2. KDA практически одинаков по всем рангам (4.4–4.7)
3. XPM зависит от длительности
4. Только CS/мин растёт линейно, но одна метрика недостаточна

### Интерпретация

**Надёжные метрики (6 из 15):** CS/мин, Last Hits, Denies, Deaths, Tower Damage + parsed-метрики (Vision, APM, Camps, Teamfight).

**Ненадёжные метрики (5 из 15):** GPM, XPM, KDA, Level, Net Worth — зависят от длительности матча и игрового режима. На Kaggle (только про-матчи Captain's Mode) они работали; на реальных Ranked данных — **не работают**.

**Объяснение различия Kaggle vs OpenDota:** Kaggle содержит только Captain's Mode матчи (профессиональная лига), где длительность стабильна (~35 мин), а GPM/XPM напрямую отражают навык. В реальных Ranked All Pick длительность варьируется (32–36 мин), и GPM/XPM больше зависят от game state, чем от skill.

## Рекомендации по обновлению системы RuPrime

### Критические изменения

| # | Действие | Обоснование |
|---|----------|------------|
| 1 | **Заменить GPM на CS/мин** в категории Farming | CS/мин: ρ=1.0 на 3 источниках, GPM: нестабильно |
| 2 | **Убрать KDA из основного скоринга** | KDA ≈ 4.5 для всех рангов, не дифференцирует |
| 3 | **Заменить XPM на APM** в Mechanics | XPM: ρ=-0.60, APM: ρ=+0.98 |
| 4 | **Использовать Deaths/мин вместо Deaths (абс)** | Нормализация на длительность убирает confounding |
| 5 | **rank_tier из API вместо эвристики MMR** | MAE эвристики = 2 700+, непригодна |

### Обновлённые приоритеты категорий

| Категория | Ключевая метрика | ρ (OpenDota v2) | Надёжность |
|-----------|-----------------|----------------|------------|
| **Farming** | CS/мин | **+1.000** | Максимальная |
| **Vision** | Obs + Sen Wards | +0.83 / +0.81 | Высокая |
| **Mechanics** | APM | **+0.976** | Высокая |
| **Objectives** | Camps Stacked | **+0.905** | Высокая |
| **Survival** | Deaths/мин | **−0.905** | Высокая |
| **Control** | Teamfight % | **+0.833** | Высокая |
| **Consistency** | Denies | **+0.833** | Высокая |
| **Combat** | Kills (инверс.) | −0.952 | Средняя* |

*Kills убывают с рангом — интерпретация: pro-игроки меньше убивают, но эффективнее.

### Контринтуитивные находки

1. **Kills убывают с рангом** (7.7 → 6.5): Immortal фокусируется на фарме и объектах
2. **GPM не растёт с рангом** в Ranked: длительность матча — главный confounding factor
3. **KDA ≈ const** (4.4–4.7) по всем рангам: одинаковое соотношение kills/deaths
4. **Net Worth убывает** с рангом: Immortal матчи короче → меньше net worth
