# Материалы для экспертного интервью (H1)

## Цель

Собрать независимые экспертные оценки слабых мест игроков для сравнения с результатами алгоритма RuPrime.

---

## Профиль эксперта

- MMR 4000+ (ранг Ancient и выше)
- Опыт тренерства / аналитики Dota 2 от 1 года
- Знакомство с основными метриками (GPM, XPM, KDA, wards, objectives)

---

## Протокол проведения

### Подготовка (до интервью)

1. Выбрать 5–10 игроков разных рангов (Herald, Crusader, Archon, Legend, Ancient, Divine)
2. Для каждого игрока подготовить **Карточку игрока** (см. ниже)
3. Запустить алгоритм и сохранить результат (НЕ показывать эксперту)
4. Распечатать анкету оценки

### Проведение (30–45 мин)

1. Представить карточку игрока эксперту
2. Попросить **независимо** оценить каждую из 8 категорий (1–10)
3. Попросить выделить **топ-3 слабых места**
4. Попросить дать **рекомендации по улучшению**
5. После оценки всех игроков — показать результат алгоритма и обсудить расхождения

## Обработка данных

Данные из анкет вносятся в блокнот `notebooks/H1_expert_validation.ipynb`:

1. Оценки эксперта (8 категорий × N игроков)
2. Оценки алгоритма (из API `/ml/detailed-features/{account_id}`)
3. Рассчитываются:
   - Cohen's Kappa для топ-3 слабых мест
   - Корреляция Спирмена по оценкам 1–10
   - Mean Absolute Difference по категориям
   - Confusion Matrix (слабая/средняя/сильная)

## Опросник для пользователей (H3: продуктовая валидация)

### Формат: 5 вопросов, Likert scale (1–5)

Проводится после того как игрок использовал сервис (привязал Steam, посмотрел Dashboard).

| # | Вопрос | 1 | 2 | 3 | 4 | 5 |
|---|--------|---|---|---|---|---|
| 1 | Статистика помогла понять свои слабые места | совсем нет | скорее нет | нейтрально | скорее да | полностью |
| 2 | Рекомендации по улучшению были конкретными | ○ | ○ | ○ | ○ | ○ |
| 3 | Подбор тренера был обоснованным | ○ | ○ | ○ | ○ | ○ |
| 4 | Я готов(а) обратиться к тренеру на основе данных | ○ | ○ | ○ | ○ | ○ |
| 5 | Рекомендую сервис другу | ○ | ○ | ○ | ○ | ○ |

**NPS (Net Promoter Score):** Вопрос 5 пересчитывается по шкале 0–10 → NPS = %promoters - %detractors

### Дополнительные вопросы (открытые)

- Чего не хватает?
- Какой ранг вы хотите достичь?
